# Portfólio Pessoal

## Descrição

Este projeto consiste em um portfólio pessoal desenvolvido com HTML5 e CSS3 como parte de um trabalho acadêmico da faculdade, realizado durante meus estudos e aprendizado dos fundamentos de desenvolvimento Front-end.

O projeto teve como principal objetivo colocar em prática os conhecimentos adquiridos em sala de aula, especialmente na criação de páginas web, estruturação de conteúdo com HTML e estilização de interfaces utilizando CSS.

## Objetivo Acadêmico

O desenvolvimento deste portfólio foi proposto como uma atividade prática durante meu processo de aprendizado em Front-end.

Através do projeto, pude aplicar conceitos fundamentais de desenvolvimento web, como:

* Estruturação de páginas com HTML5;
* Criação de layouts utilizando CSS3;
* Organização de conteúdo em diferentes seções;
* Utilização de links e navegação interna;
* Aplicação de cores, espaçamentos, tipografia e elementos visuais;
* Desenvolvimento de uma página com apresentação pessoal e profissional.

## Sobre o Projeto

A página foi desenvolvida para apresentar informações pessoais, habilidades, projetos e formas de contato.

O projeto possui um cabeçalho com apresentação e navegação, além das seções "Sobre mim", "Habilidades" e "Projetos". Também conta com uma área destinada a redes sociais e informações de contato.
O visual da página foi desenvolvido utilizando CSS, com definição de cores, tipografia, espaçamentos, organização dos elementos e estilização das diferentes seções.

## Aprendizados

Este projeto foi uma das experiências práticas do meu processo de aprendizado em Front-end. Durante seu desenvolvimento, pude compreender melhor como HTML e CSS trabalham juntos para construir e estilizar uma página web.

Além de aplicar conceitos técnicos, o projeto também serviu como uma oportunidade para organizar informações pessoais e apresentar meus primeiros trabalhos relacionados à programação.
